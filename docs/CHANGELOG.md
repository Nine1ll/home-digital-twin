## 2026-09-30 · 집 만들기와 생활 기능 (`home-builder` 브랜치)

### fix(ui): 시트가 열려 있어도 토스트가 보이게

- 모달 `<dialog>`는 최상위 레이어에 그려져서, 시트가 열린 상태의 오류 토스트(예: 공간 삭제 실패)가 시트 뒤에 가려졌습니다.
- 토스트를 `popover="manual"`로 바꾸고 표시할 때마다 다시 열어 가장 위 레이어로 올립니다. popover 미지원 브라우저는 기존 class 방식으로 표시합니다.
- 검증: 하위 공간이 있는 주방 삭제 → 시트 위에 오류 토스트 표시 확인(스크린샷).

### feat(ui): 공간 만들기를 이름 하나로

- 이전에는 새 공간마다 종류와 좌표 4개(가로·세로 위치, 너비, 높이)를 숫자로 넣어야 했고, 기본 위치가 항상 (0, 0)이라 기존 공간 위에 겹쳐 생겼습니다.
- **종류 자동 선택**: 최상위는 방, 방 안은 가구, 그 안은 수납 칸(바꿀 수 있음).
- **빈자리 자동 배치**: 형제 공간과 겹치지 않는 첫 자리를 위→아래, 왼→오 순서로 찾습니다. 꽉 차면 8×6 → 6×4 → 4×3 → 2×2로 줄여 찾습니다.
- 좌표 입력은 ‘위치·크기 직접 입력’으로 접었습니다. 새 공간 시트가 열리면 이름 칸에 바로 커서가 갑니다.
- 상위 공간을 바꾸면 종류와 빈자리를 다시 고릅니다.
- 검증: 주방 안에서 ‘+공간’ → 종류 ‘가구’, 기존 냉장고·수납장과 겹치지 않는 (0, 8)에 배치, 가구 안에서는 ‘수납 칸’.

### fix(ui): 활동 기록 시간을 기기 시간대로 표시

- 서버의 UTC 시각을 그대로 잘라 `UTC`를 붙여 보여줘서 한국에서는 9시간 늦게 보였습니다.
- `8. 5. 오전 10:00`처럼 기기 시간대로 바꿉니다. SQLite는 시간대 표시(`+00:00`)를 잃으므로 없으면 UTC로 해석합니다.

## 2026-09-30 · 모바일/태블릿 UX 개편 (`mobile-ux` 브랜치)

목표: 휴대폰과 태블릿에서 한 손으로 쓰기 좋은 앱. 참고 레퍼런스는 Toss(바텀시트, 큰 터치 영역, 한국어 문장형 UI), Apple 홈 앱(공간 탐색), Sortly(폴더형 재고 목록)입니다.

### feat(ui): 앱으로 돌아오면 자동 새로고침

- 홈 화면 앱은 백그라운드에 오래 남아 있어, 다시 열었을 때 가족이 바꾼 재고와 새 알림이 보이지 않았습니다.
- 화면이 다시 보이면(`visibilitychange`) 30초 이상 지난 경우에만 새로 불러오고 스크롤 위치를 유지합니다.
- 입력 중인 등록 화면이나 열린 시트가 있으면 건너뜁니다(작성 중인 내용 보호).
- 검증: 폰 뷰포트 E2E로 사용(스테퍼 +1) → 시트에서 옮기기 → 위치 보기 강조 → 바깥 탭으로 시트 닫기 → 새 물건 등록까지 통과, 페이지 에러 0건. `pytest` 16 passed.

### feat(ui): 모바일 우선 화면 개편

- **내비게이션**: 폰은 아이콘이 있는 하단 탭(가운데 ‘등록’ 강조), 태블릿(700px~)은 왼쪽 레일, 데스크톱(1200px~)은 사이드바. 알림 탭에 확인할 개수 배지.
- **바텀시트**: 폰에서 모든 대화상자가 아래에서 올라오고, 바깥을 누르면 닫힙니다. 태블릿부터는 가운데 카드.
- **물건 행**: 버튼 5개 대신 `이름·D-day·위치 | 수량 | 사용` 한 줄. 행을 누르면 사용/옮기기/위치 보기/수량 정정/폐기 시트가 열립니다.
- **수량 스테퍼**: 수량·구매 기준·임박 기준을 −/+ 버튼으로 조절(키보드 없이 한 손 조작).
- **등록 화면**: 바코드 스캔·번호·사진 타일을 맨 위로. 사진은 고르는 즉시 인식. BarcodeDetector가 없는 브라우저(iOS Safari 등)에서는 스캔 타일을 숨깁니다.
- **위치 보기**: 보관 칸이 들어 있는 상위 공간을 열고 그 칸을 강조합니다(이전에는 칸 내부로 진입).
- **태블릿**: 760px 이상에서 배치도와 물건 목록을 좌우 2단으로, 목록은 스크롤 고정.
- **찾기**: 입력 전에도 전체 물건 표시, 검색창 상단 고정, 엔터는 키보드만 내림.
- **설정**: 초대 코드를 공유 시트(카톡·문자)로 보내기, 로그아웃을 상단 바에서 설정 → 계정으로 이동.
- **다크 모드**: `prefers-color-scheme`로 자동. 색은 모두 `:root` 토큰으로 정리.
- **터치**: 버튼 최소 44px, 입력 16px(iOS 확대 방지), hover 스타일은 마우스 기기에만, 누름 피드백, safe-area 여백, `100dvh`.
- 용어 ‘소비’를 화면에서는 ‘사용’으로 표기(API의 `consume`은 그대로).
- 쓰이지 않던 CSS(`.span2`, `.progress`, `.photo-preview`, `.list`, `.mobile-title`) 삭제.

### feat(pwa): 홈 화면에 앱으로 설치

- `manifest.webmanifest`와 아이콘(192/512/maskable/apple-touch)을 추가했습니다.
- `viewport-fit=cover`로 노치·홈 인디케이터 영역까지 그리고 safe-area로 여백을 맞춥니다.
- iOS: 사파리 공유 → 홈 화면에 추가. Android: Chrome 메뉴 → 앱 설치.
- 서비스워커(오프라인)는 넣지 않았습니다. 모든 데이터가 서버에 있어 오프라인 화면만으로는 쓸 일이 없기 때문입니다.
